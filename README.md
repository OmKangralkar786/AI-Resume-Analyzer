# AI Resume Analyzer

AI-powered Resume Analyzer built using React and Django.

## Features

* User Registration & Login
* Resume Upload
* ATS Score Analysis
* Skill Extraction
* Missing Skill Detection
* AI Suggestions
* Interview Question Generator
* Resume Strength & Weakness Analysis
* Career Recommendation Engine
* Resume History
* Analytics Dashboard
* PDF Report Download

## Technologies Used

### Frontend

* React.js
* Bootstrap
* Axios
* Framer Motion

### Backend

* Django
* Django REST Framework
* SQLite

## Installation

### Backend

```bash
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### Frontend

```bash
cd frontend
npm install
npm start
```
